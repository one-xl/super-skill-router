# Skill Update Proposal

## 更新类型

新增

## 目标文件

`BUSINESS_SKILL_ROOT/frontend/auth-form/INSTRUCTION.md`

## 更新原因

多次任务都需要处理登录、注册、找回密码等认证表单，现有 `web-frontend` 示例 Skill 过于通用，缺少可复用的认证表单流程。

## 建议内容

```md
# Auth Form

## 执行流程

1. 确认认证场景：登录、注册、找回密码或重置密码。
2. 明确字段、校验规则、错误状态和提交状态。
3. 复用项目已有表单组件和请求封装。
4. 保证键盘可用、错误提示清晰、提交过程有明确反馈。

## 输出要求

- 给出表单结构和关键交互。
- 说明需要的后端接口契约。
```

是。默认不自动修改文件。
