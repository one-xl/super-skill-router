# Engineering Development Skill Tag

## 标签

TDD、测试驱动、Debug、调试、诊断、架构重构、软件工程、敏捷开发、Zoom-out

## 适用场景

- 编写测试驱动的代码，进行 Red-Green-Refactor 循环开发。
- 精准诊断定位复杂 Bug、崩溃或性能退化问题，构建可靠的反馈回路（Feedback Loop）。
- 寻找 codebase 重构深度化机会，重构混乱代码，保持行为不变。
- 站在宏观（Zoom-out）视角探索陌生大块代码或高难度的全局控制流程。

## 读取完整 Skill 的条件

- 需要开始执行高标准的测试驱动开发循环（读取 `tdd`）。
- 需要执行严格的诊断循环（Repro -> Hypothesise -> Instrument -> Fix -> Regression-test）（读取 `diagnose`）。
- 需要分析和重新梳理架构依赖与设计机会（读取 `improve-codebase-architecture`）。
- 需要系统指导如何探索极度陌生的庞大代码段（读取 `zoom-out`）。
