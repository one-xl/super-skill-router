# Engineering Planning Skill Tag

## 标签

需求规划、PRD、Issue拆解、Grill-me、方案审查、设计对齐

## 适用场景

- 通过提问、质疑和双向对齐，消除技术方案中的多义性与架构隐藏漏洞。
- 将零散的用户想法编写成规范的 PRD（产品需求文档），提交给团队。
- 将庞大的需求方案按“垂直切片”（Vertical Slice）的思路，拆解成若干完全独立、可单独分发交付的 GitHub Issues。

## 读取完整 Skill 的条件

- 需要使用 Grill-me 系统性拷问设计决策，并同步更新 `CONTEXT.md` 时（读取 `grill-me`）。
- 需要把复杂的工程任务精准垂直切割并转为 Issue 卡片时（读取 `to-issues`）。
- 需要自动将复杂上下文提取并写出 PRD 时（读取 `to-prd`）。
