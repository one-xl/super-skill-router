# Frontend Category Tag

## 分类用途

处理浏览器端页面、组件、样式、交互和前端工程任务。

## 命中条件

- 用户要求创建、修改或优化页面。
- 用户提到 UI、组件、布局、表单或样式。
- 用户任务涉及 HTML、CSS、JavaScript、TypeScript、React、Vue 或浏览器端行为。

## 排除条件

- 只涉及服务端接口或数据库逻辑时，优先选择 `backend`。
- 只涉及部署、域名、反向代理或线上访问时，优先选择 `deployment`。
