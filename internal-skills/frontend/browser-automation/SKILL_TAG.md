# Browser Automation Skill Tag

## 标签

浏览器、Chrome、DevTools、MCP、自动化、测试、截图、Screenshot、Puppeteer、调试、Performance、Console、Network

## 适用场景

- 使用 Chrome DevTools MCP 连接并控制浏览器。
- 对前端界面进行自动化交互测试与实时渲染截图。
- 分析网页网络 API 响应与页面渲染性能（Performance Timeline）。
- 检索 Console 报错和 JS 调用栈。

## 读取完整 Skill 的条件

- 任务涉及控制浏览器导航、点击、输入或截图等操作。
- 需要设置特定的 Puppeteer / Chrome 端口连接参数。
- 需要诊断特定的前端报错、慢加载节点或接口异常。
