# Web Frontend - Comprehensive Skill

This skill is the central entrypoint for all web frontend tasks. It integrates styling, layout composition, animation choreography, accessibility, AI-prose/pattern linting, and premium aesthetic guidelines.

## Execution Workflow

1. **Analyze Requirements & Constraints**:
   - Confirm framework/libraries (React, Vue, Next.js, Vite, Vanilla HTML/JS, Tailwind, etc.).
   - Define responsiveness (breakpoints), safe-areas (mobile notches, bars), and basic typography scale.
2. **Select Aesthetic & Design System**:
   - Commit to a distinctive, non-generic style (e.g., Neo-Brutalist, Editorial, Glassmorphism, Swiss Modernism).
   - Establish font pairing and harmonious, context-appropriate colors. Refer to [Frontend Design]([frontend-design](INSTRUCTION.md)) and [UI/UX Pro Max]([ui-ux-pro-max](INSTRUCTION.md)).
3. **Draft Layout & Interactions**:
   - Ensure clean grid/flex layout (asymmetry, break-the-grid, diagonal flows where appropriate).
   - Implement motion / animations. Refer to [GSAP Animation]([gsap](internal-skills/gsap/INSTRUCTION.md)) for timelines, ScrollTrigger, performance, and framework lifecycle hooks.
4. **Audit and Refine (Taste & Anti-Patterns)**:
   - Run a strict design check. Prevent overused/generic layouts and mechanical tells (e.g., "poetic-labels", "generic stage labels", "serif VERY DISCOURAGED as default", "Logo-Only rule"). Refer to [Taste & Aesthetic Guidelines](../taste-skill/INSTRUCTION.md).
   - Clean up AI tells or marketing prose tells. Prevent "load-bearing", "highest-leverage", "delve", "elevate", "empower". Refer to [Impeccable Anti-Patterns](../impeccable/INSTRUCTION.md).
5. **Verify Usability & Code Quality**:
   - Verify keyboard navigation, ARIA attributes, and color contrast (4.5:1 min for text).
   - Test layout responsiveness, performance, and loading/error states.

## Detailed Sub-Manuals Index

When working on specific aspects of frontend development, you **MUST** read the detailed sub-manuals below:

### 1. [Frontend Design Manual]([frontend-design](INSTRUCTION.md))
* **Focus**: Bold and memorable page/component design, typography pairing (avoiding Inter/Roboto), color systems, spatial layout asymmetry, clip paths, noise textures.
* **When to load**: Changing visual appearance, styling landing pages, dashboards, portfolios, e-commerce grids.

### 2. [UI/UX Pro Max Guide]([ui-ux-pro-max](INSTRUCTION.md))
* **Focus**: Production-grade UX quality control. 99 guidelines covering accessibility (WCAG AA), touch target boundaries (44x44pt min), loading skeletons, form validation cycles, and responsive layout safety.
* **When to load**: Reviewing navigation patterns, form feedback loops, data tables, charting elements, or accessibility optimization.

### 3. [GSAP Animation Manual]([gsap](internal-skills/gsap/INSTRUCTION.md))
* **Focus**: Comprehensive GSAP documentation. Covers core tweens, timeline choreography (`gsap.timeline`), scroll-driven pinning (`ScrollTrigger`), framework bindings (React `useGSAP`, Vue, Svelte), utility helpers (`gsap.utils`), and animation performance (preventing layout thrashing).
* **When to load**: Writing motion code, page transitions, hover states, scroll-bound visuals.

### 4. [Impeccable Anti-Patterns Checklist](../impeccable/INSTRUCTION.md)
* **Focus**: Clean design, editorial controls, and eliminating generic AI prose Tells. Check list of words and sentences that sound like robotic templates.
* **When to load**: Refining documentation, reviewing marketing copy, ensuring high-quality editorial code comments.

### 5. [Taste & Aesthetic Hardening Guide](../taste-skill/INSTRUCTION.md)
* **Focus**: Hard rules preventing common agent design failures. Includes rules against: Fraunces/Instrument Serif as default, beige/brass/espresso cookware palettes, CTA button text wraps, split-headers, and zigzag alternation.
* **When to load**: Final review before delivering user-facing UI screens.
