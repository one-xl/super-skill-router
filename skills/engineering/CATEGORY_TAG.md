# Engineering Category Tag

## 分类用途

处理软件工程开发中的通用最佳实践、测试驱动开发（TDD）、缺陷与性能诊断调试、代码架构重构、快速原型构建、会话交接、宏观视角探索、交互式设计对齐，以及需求规划拆解（PRD/Issues）。

## 命中条件

- 用户提到 TDD、测试驱动、编写单元/集成测试。
- 用户需要调试、修Bug、诊断复杂问题、处理崩溃或死锁。
- 用户要求重构设计、评估代码架构、或探索陌生大型模块。
- 用户需要编写 PRD、将大任务拆解为细粒度 Issue 列表、或者进行设计方案的 Grilling 交互对齐。
- 用户任务涉及会话交接或快速原型搭建。

## 排除条件

- 只涉及具体的前端 CSS 布局/视觉重构时，优先选择 `frontend`。
- 只涉及纯粹的部署运行、服务器 Nginx/Docker 配置时，优先选择 `deployment`。
- 纯粹的商业文档/非工程类说明书写作，优先选择 `document`。
