# Engineering Subcategory Index

## development

标签：TDD、测试驱动、Debug、调试、诊断、架构重构、软件工程、敏捷开发、Zoom-out  
读取条件：用户任务涉及编写测试、修Bug调试、重构架构或者高空审视模块代码时读取。  
读取：engineering/development/SKILL_TAG.md

## prototyping

标签：原型设计、抛弃型原型、命令行程序、界面多分支、快速验证、throwaway  
读取条件：用户任务涉及开发 throwaway 原型以验证核心业务逻辑、网络或多套 UI 分支对比时读取。  
读取：engineering/prototyping/SKILL_TAG.md

## planning

标签：需求规划、PRD、Issue拆解、Grill-me、方案审查、设计对齐  
读取条件：用户任务涉及交互式审查方案、编写需求 PRD 文档、将大型需求转化为垂直切片 GitHub Issues 时读取。  
读取：engineering/planning/SKILL_TAG.md

## collaboration

标签：交接、Handoff、会话总结、接力开发、Session  
读取条件：用户任务涉及对当前开发进度进行细致总结，以交接给下一个 AI 代理或新会话接力时读取。
