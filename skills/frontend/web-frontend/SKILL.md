# Web Frontend

## 执行流程

1. 先确认现有前端技术栈和组件约定。
2. 优先复用已有组件、样式变量和目录结构。
3. 实现时关注布局稳定性、响应式、交互状态和可访问性。
4. 避免引入无关 UI 框架或大范围重构。
5. 完成后运行项目已有的格式化、检查或测试命令。

## 输出要求

- 说明主要修改点。
- 说明已验证的命令或未能验证的原因。
- 如果形成可复用 UI 规范，生成 Skill Update Proposal。
